# CopperToolchain

A self-documenting project: its own creation, decisions, and progress are logged here,
and it grows reusable scripts, processes, and plans for other projects.

- `log/` - dated session logs, written by `scripts/log-turn.sh`
- `log/log.md` - hand-edited record of the founding conversation
- `scripts/` - project tooling (`log-turn.sh`, `sync.sh`, `setup-repo.sh`)
- `assets/` - expertise and hardware inventory
- `docs/`, `templates/` - decisions and reusable material
