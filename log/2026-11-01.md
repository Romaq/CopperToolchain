### The likely problem: turn numbering

The script finds the current turn number by searching for headings that start with the exact text `## 🧑 USER · Turn`. If you changed the label only where the script **writes** the heading, new entries will say `Romaq`, but the number-finding line will still look for `USER`. Numbering would then stop advancing, and new messages could keep landing on the same turn number.

To check, look at your last two logged messages. If both show the same turn number, this is the cause.

The fix is one line in `scripts/log-turn.sh`, in the `maxturn` function. Change the pattern so it accepts any label:

```bash
# before
grep -hoE '^## 🧑 USER · Turn [0-9]+' "$1" 2>/dev/null | ...

# after
grep -hoE '^## 🧑 [^·]+ · Turn [0-9]+' "$1" 2>/dev/null | ...
```

With that change, both old `USER` headings in `log.md` and new `Romaq` headings are counted, so numbering stays continuous across the switch.
