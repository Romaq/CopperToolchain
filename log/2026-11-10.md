### 1. Attribution: the heading is the authority

The old script wraps any `claude` clipboard text that lacks a leading `---` in a hard-coded `CLAUDE` heading. A ChatGPT reply pasted that way would be silently logged as Claude, which is the failure you named. Proposed rule:

- **The AI's own heading decides who wrote it.** It must match `## <emoji> <short_name> <AI> · Turn N · date`, for example `## 🤖 TLC CHATGPT · Turn 3 · 2026-11-10`.
- **The separator must stay `·`.** Your "TLC CHATGPT Turn N" has no separators. The script's patterns key on ` · Turn N`, so an unseparated heading wouldn't be recognised. Matching the Claude style fixes that.
- **The script validates before writing.** The project must equal the active project, and the AI name must be in an allowed list (in `project.conf`, for example `participants: CLAUDE CHATGPT`).
- **If any check fails, the script refuses.** It exits non-zero with a notification naming the reason, and appends nothing. It never defaults to `CLAUDE`.
- **Numbering is unaffected.** `maxturn` counts only the user's `🧑` headings, so AI headings can't disturb it.
- **ChatGPT must produce that heading itself.** Put the format in its instructions, the same way Claude has it.

The alternative is an opening marker line such as `AI CHATGPT`, but that is a second mechanism to remember. Heading only is simpler, and a wrong paste is rejected anyway.
