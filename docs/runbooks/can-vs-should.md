# Five Rules for adding services on the Home Lab

> "Yeah, yeah, but your scientists were so preoccupied with whether or not they could that they didn't stop to think if they should." -- Ian Malcolm, Jurassic Park (1993)

The checklist below is one of the project's design maxims. The rest are in `design-maxims.md` in this folder.

1. What problem does it solve today?
2. What breaks if it fails?
3. How many minutes a month does it cost to maintain?
4. Could I rebuild it from a short written recipe?
5. Is there an existing tool, or a simpler 80% solution?

If every answer is poor and every option still looks bad, see "Sometimes all options suck" in `design-maxims.md`.
